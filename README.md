# README - Telecom - analysis

## Objetivo del proyecto

El objetivo del proyecto fue analizar el comportamiento de consumo de los usuarios de Telecom tomando en cuenta distintas variables como la edad, la fecha, la clasificación de uso, entre otras. 

## Datasets utilizados

plans.csv: los planes actuales (precio, minutos incluidos, GB incluidos, costo por extra).
users_latam.csv: información de clientes: edad, ciudad, fecha de registro, plan contratado.
usage.csv: el detalle de uso real: llamadas (duración) y mensajes (longitud).

## Etapas del análisis

En un inicio se cargan los datasets mencionados anteriormente, se exploran los datos para asegurar la calidad de los mismos, identificando valores nulos o inválidos.

Posterior a los anteriores pasos se limpian los datos para realizar un análisis con datos acertados y a partir de estos datos se sacan estadísticas de datos relevantes como el conteo, el mínimo, el máximo, el promedio, entre otros.

A continuación se sacan visualizaciones de los datos, con histogramas y gráficos de barras y bigotes para visualizar mejor la distribución de los datos para de esta forma encontrar los outliers dentro de los datos.

Posterior a la visualización y la identificación de outliers, se procede a realizar la segmentación de los datos para visualizar grupos divididos por nivel de uso y edad.

Finalmente, se generan hallazgos y recomendaciones finales a partir de los datos encontrados en el análisis con el objetivo de mejorar las ganancias de la organización.
